Sakshi / Innovation research / 02 October 2026

The differentiator is what happens when the evidence is imperfect.

The ingredients already exist. A stronger Sakshi would know what it did not capture, let corrections change its conclusions, and let a recipient check exactly what was disclosed.

No confirmed world-first invention. Tier A below identifies narrow, evidence-backed differentiation opportunities relative to inspected systems. It does not establish patent novelty, market exclusivity, or implemented Sakshi capabilities.

Research overview. The full assessment, all 11 requested fields for each innovation, evaluation plan and 30 source groups are in research/technical-differentiation-novelty-stack.md. Product claims are not independent performance or security validation. No Android/device execution was performed.

Three behaviors worth proving

I1 / Tier A candidate

Capture-aware patterns

A listener reconnects and captures more messages. Do not call that escalation. Distinguish changed observation from changed incidents.

Proof: fewer false trends than naive counts under duplicate, outage and visibility changes.

I2 / Tier A candidate

Correction-aware lineage

A user rejects a false event. Every dependent pattern and current report updates. Originals and past signed reports remain unchanged.

Proof: valid source spans, transactional propagation, no stale retrieval or export.

I3 / Tier A candidate

Checkable disclosure

A user selects what to share. A second offline machine verifies the bundle. Omitted originals and signer-trust limits are explicit.

Proof: tamper detection, scope/approval invariants and redaction leak tests.

Novelty Stack

A

Strong comparative differentiation opportunities

I1 capture-aware patterns; I2 correction-aware evidence lineage; I3 reviewed, selectively disclosed, offline-verifiable analytical bundles.

Established mechanisms, less-evidenced exact survivor integration. No confirmed novel algorithm or patentable invention. Implementation and ablation required.

B

Interesting, needs validation

I4 review-aware retrieval; I5 pipeline uncertainty; I6 Indic acquisition robustness; I7 reversible personalization; I8 cross-modal alignment; I9 custody/recovery assurance; I10 full-pipeline quality/energy evaluation.

The full-stack combination is also conditional: broad local-AI survivor evidence prototypes already exist.

C

Common or clearly precedented

Local inference, OCR/STT, notification classification, multilingual encoders, timelines, adaptive classifiers, generic offline RAG, citations, review buttons, encrypted vaults, hashes/signatures, PDF exports, quantization, routing, calibration and abstention techniques.

Common means category-relative/substantial prior art, not measured market share. These remain necessary foundations.

D

Unrealistic or too risky as promised

Future-harm/legal verdict scores; universal private-app or View Once access; guaranteed ten-language accuracy; always-on high-compute surveillance; effortless per-correction LLM training; automatic identity certainty; root-proof privacy; blockchain/admissibility guarantees; automatic panic wipe.

Innovation assessment cards

Condensed engineering assessments. Expand each card for precedent, gap, mechanism, models, feasibility, data, security, privacy, effort, demo and failure modes. Full rationale and source IDs are in the Markdown report.

I1 / A candidate - Capture-aware temporal analysis
Precedent
2017 notification/fuzzy accumulation; Agent Hita; UCD/temporal HAN.
Gap
Known capture changes must influence trend eligibility, not just incident scores.
Mechanism
Source/time provenance, listener windows, conservative deduplication and incomparable-coverage abstention. Connected does not mean complete.
Models
Small category classifier or validated Laya plus deterministic window rules; no LLM needed.
Android
Bookkeeping feasible; actual message visibility is partial and outages can be unknown.
Data
Timestamped labeled sequences and capture logs; loss/grouping/update/import/time-zone fixtures.
Security
Authenticate capture records; imported sender/time remain claimed.
Privacy
Encrypt observation logs and frequency metadata, not just text.
Effort
Medium rules/replay; High evaluation across devices/apps.
Demo
Constant incident rate with better capture fools naive count but not Sakshi; real change with comparable capture remains visible.
Failures
Non-random missingness, false merges, undetected gaps and false reassurance. No unavailable-content recovery.
I2 / A candidate - Correction-aware dependency graph
Precedent
Aimee event modification; BullyAlert feedback; C2PA lineage; Axon audit.
Gap
Enforce every dependency from original through derivative, correction, pattern and report.
Mechanism
Immutable originals; versioned derivatives/findings/corrections; recompute dependent aggregates/indexes; preserve superseded report snapshots.
Models
OCR/STT/classifier; templates; optional constrained local LLM.
Android
SQLite graph plus encrypted blobs is practical; Unicode offsets and transactions need care.
Data
Aligned spans, correction histories, merge/split/date/speaker and stale-index fixtures.
Security
Validate edges/hashes; append-only alone does not prevent compromised-device rollback.
Privacy
Correction history is sensitive and not automatically exported.
Effort
Medium text graph; High multimodal/migration work.
Demo
Reject one event, show current counts/search/report change and unchanged original/past report; invented source ID fails.
Failures
Stale links, offset drift, coerced labels, valid citation to wrong interpretation. User approval is not truth.
I3 / A candidate - Selective checkable disclosure
Precedent
TalkingParents signed PDFs; Proofmode/C2PA; Tella transfer; Axon disclosure.
Gap
Reviewed AI scope plus explicit original/derivative/omission states, independent of Sakshi.
Mechanism
Preview selection; sanitized copies; canonical signed manifest, report and chosen assets; offline verifier; explicit recipient/key transfer.
Models
None for verification; optional reviewed redaction suggestions.
Android
Bounded export/signing feasible; reliable redaction/packaging is harder.
Data
PDF layers, EXIF, filename, thumbnail, quote and archive tamper/leak fixtures.
Security
Compare signer fingerprint independently where needed; signature cannot prove source truth or trusted time.
Privacy
Redacted originals must not leak in the same bundle. Hidden parents are not independently checkable without access.
Effort
Medium text manifest; High safe multimodal redaction/trust.
Demo
Verify on second offline machine; mutate source/report/edge and fail; show unavailable-original status.
Failures
Metadata leaks, key substitution/loss, wrong recipient, incomplete report treated as complete. No zero-knowledge/admissibility claim.
I4 / B - Review-aware local evidence retrieval
Precedent
AnythingLLM local document RAG; Aimee survivor document search.
Gap
Case isolation, review/version-aware filtering and evidence answerability.
Mechanism
Lexical baseline, optional dense ranking, exact snippets/context; database counts, not top-k counts; separate source-search from approved-label search.
Models
None for lexical search; multilingual MiniLM candidate, optional small local LLM.
Android
Bounded corpus practical; index/LLM/ASR residency must be measured.
Data
Relevant-span query pairs, unanswerable/negative/code-mix/prompt-injection cases.
Security
Evidence text is untrusted data, never authority for tools/export.
Privacy
Encrypt embeddings, index, queries and caches. No silent remote fallback.
Effort
Medium search/filtering; High reliable generation.
Demo
Find exact sources, abstain on unsupported fact, exclude other case and propagate corrections.
Failures
Top-k omission mistaken for absence, stale index, hallucination and cross-case leakage.
I5 / B - Pipeline uncertainty and abstention
Precedent
Fuzzy decisions; Laya abstention/calibration; selective conformal research.
Gap
Capture, extraction, language/domain, classifier and pattern uncertainty remain separate.
Mechanism
Quality gates, disjoint calibration, thresholds and explicit review/unsupported/context states. No multiplied confidence danger score.
Models
Classifier scores and extraction checks; no large model required.
Android
Postprocessing is easy; defensible rare-outcome calibration is not.
Data
Adjudicated grouped calibration/test, rare threats, corruption and shift slices.
Security
Adversarial media can cause confident error or abstention; keep source evidence.
Privacy
No compulsory upload for confidence tuning.
Effort
Medium gates; High/Very high statistical validation.
Demo
Degraded evidence moves to review; few synthetic examples do not prove calibration.
Failures
Confident errors, unequal abstention, broken exchangeability and hidden false negatives.
I6 / B - Indic acquisition-realistic robustness
Precedent
DravidianCodeMix/DravidianLangTech; HASOC; multilingual models.
Gap
Private-context, code-mixed and OCR/STT robustness, not another UI translation.
Mechanism
Preserve scripts; derivative normalization; language/modality gates; compact model tuning, calibration, export and end-to-end evaluation.
Models
Multilingual classifier; script-appropriate OCR; multilingual STT.
Android
Text easiest. ML Kit does not list several requested Indic scripts; all-language multimodal MVP is not assumed.
Data
All requested language slices over time; real/synthetic/source/license/context recorded. Public offensive comments are not escalation labels.
Security
Version normalization; keep all derivatives of one item in one split.
Privacy
Consent for private chats; licensed public data does not authorize survivor scraping.
Effort
High two-language pilot; Very high full validated coverage.
Demo
English + Malayalam/Romanized text slice; unsupported varieties clearly unvalidated.
Failures
Dialect/slang, polite coercion, negation/transcription errors, label mismatch and leakage.
I7 / B - Reversible local personalization
Precedent
BullyAlert phone adaptation; PI-Bully; local RAG memory.
Gap
Case-scoped, reversible context/preference adaptation without rewriting past evidence.
Mechanism
Encrypted reviewed examples/context, confirmed aliases, bounded thresholds; base result and personalized suggestion stored separately; reset.
Models
Existing encoder/embedder; optional tiny head, no LLM LoRA needed.
Android
Context memory practical; training requires separate runtime/parity tests.
Data
Diverse reviewed examples, untouched later holdout, poisoned/coerced corrections.
Security
Feedback poisoning through coercive phone access needs rollback and visibility.
Privacy
Local identifying memory; cache invalidation after reset.
Effort
Medium memory; High valid learning benefit.
Demo
Context changes a suggestion, reset restores base; previous signed report unchanged.
Failures
Overfit, confirmation bias, drift, cross-case contamination and normalizing repeated harm.
I8 / B - Cross-modal event alignment
Precedent
XBully/UCD; local voice evidence prototypes; Aimee mixed-document events.
Gap
Exact source intervals and uncertainty without counting one incident three times.
Mechanism
OCR regions/order, audio segment offsets and video parent links; propose duplicate/event links for user confirmation.
Models
OCR/STT plus text classifier; optional duplicate embeddings/hash.
Android
Text/screenshot practical; short audio conditional; long video stretch only.
Data
Aligned representations, quotes/recollections, speaker/date ambiguity and duplicate negatives.
Security
Bound media parser resources and preserve original bytes.
Privacy
Bystander/adjacent content also enters transcripts and indexes.
Effort
High audio alignment; Very high general video/identity matching.
Demo
Screenshot+notification duplicate candidate and one audio excerpt with explicit uncertain links.
Failures
Wrong speaker, narration mistaken for observation, false merges and invented timestamps.
I9 / B - Tested offline custody and recovery
Precedent
Tella protection/transfer; local vault prototypes; Android Keystore.
Gap
Assurance across every derivative/index/cache and understandable recovery choices.
Mechanism
Private encrypted blobs/database/index, nonce discipline, authenticated metadata, Keystore lock policy, explicit wrapped-data-key recovery and backup rules.
Models
None; inference must not leak in logs/temp files.
Android
Crypto feasible; locked background capture/authentication tradeoff and StrongBox availability vary.
Data
Synthetic crash/reinstall/key-loss/import/export/backup tests.
Security
Non-exportable keys can still be used on a compromised device. Local-only is single-device loss risk.
Privacy
Recovery expands access; no hidden backup or guaranteed invisibility.
Effort
Medium bounded vault; High safe recovery/assurance.
Demo
Encrypted-at-rest fixtures, restart and explicit recovery, not a security certification.
Failures
Plaintext WAL/log/thumbnail/cache, nonce reuse, key loss, coercive unlock and destructive panic wipe.
I10 / B evaluation, C technique - Resource-aware cascade
Precedent
Laya routing; mobile runtimes; sequential feature selection; standard quantization/caching.
Gap
Full-pipeline quality/energy evidence, not a new routing technique.
Mechanism
Compact classifier, optional bounded local LLM, review gate, versioned cache, deferred heavy work, one active model. Retain opted-in subtle/non-flagged evidence.
Models
Classifier/Laya; optional small GGUF/LiteRT-LM; OCR/STT on demand.
Android
Bounded pipeline feasible; actual accelerator/device compatibility must be tested.
Data
Normal traffic, subtle harm, ambiguous/long contexts and thermal workloads.
Security
Verify model assets and avoid sensitive profiling output.
Privacy
No silent cloud fallback; downloads explicit outside evidence flow.
Effort
Medium cascade; High device comparisons.
Demo
Phone p50/p95/RAM versus classifier-only and always-LLM, with quality/coverage also reported.
Failures
Filter false negatives, quantization/calibration drift, overheated fallback, stale cache and fluent wrong explanations.

Android and model gates

Notification access is partial

Permission and connection are not a complete conversation. Grouping, updates, previews, work profiles and gaps matter. Android 15 redacts OTP-bearing notifications for untrusted listeners.

Official Android limitations

Indic OCR is not solved by ML Kit

ML Kit lists Latin, Devanagari, Chinese, Japanese and Korean. Malayalam/Tamil/Telugu/Kannada/Bengali need another tested path. Bundled models avoid first-use download dependency.

Bundled/unbundled OCR

Laya is not a ready mobile verdict

322M multilingual / 421M English. Its multilingual card says ships uncalibrated; low-resource weaknesses and ordinal bias are documented. ONNX/tokenizer parity and Android latency need proof.

Model card Limits
Keystore protects key material, not all plaintext. A compromised process/device may use keys. StrongBox support varies. Encryption/signatures do not prove authenticity, safety or admissibility.

Memory arithmetic is planning, not a benchmark. 10,000 × 384 float vectors occupy about 14.6 MiB before indexes, text and model weights. A nominal 0.5B 4-bit model has roughly 250 MB raw weights, but activations, KV cache, runtime and app overhead add memory. Run heavy stages sequentially and benchmark a named physical phone.

Hackathon: prove I1 + text-first I2 + bounded I3

Use clearly labeled synthetic evidence. This demonstrates engineering behavior, not real-world survivor accuracy. No app implementation is established in this workspace yet.

Acquire through supported workflows

Real Android notification plumbing and share/file import. Controlled notifications do not prove complete WhatsApp capture.

Preserve and link

Hash original bytes, create a separate OCR derivative, and attach local classifier suggestions to source regions.

Show what missing capture changes

Replay duplicates/outage/visibility changes. Compare against naive counts. Unknown is not safe.

Correct a false event

Counts, current patterns, label search and report update. Originals and previous report stay fixed.

Disclose only selected evidence

Preview approval/omissions/redaction. Verify the bundle on a second offline machine; disposable tampered copies fail.

Publish the limits and measurements

Named phone/OS/model revision, p50/p95/RAM, capture limitations, unsupported languages and network instrumentation.

Optional stretch: one short multilingual audio clip or source-only lexical retrieval. Do not make a new STT stack, general RAG and an untested LLM all critical-path dependencies.

Do not pitch: violence prediction, legal verdicts, complete message access, all-language accuracy, root-proof privacy, zero-knowledge proof of correct AI, or guaranteed court admissibility.

Source anchors and evidence limits

  • Aimee founder transcript: generated events, review and modification.
  • Agent Hita: developer local/temporal claim, not independent efficacy.
  • BullyAlert, MobiCASE 2020: adaptive phone-side classifiers.
  • 2017 notification/fuzzy paper: primary indexed sections; direct PDF fetch binary.
  • AnythingLLM Mobile: released Android local RAG.
  • SaakshiAI, SilentWitness, Silent Witness PWA: distinct prototype claims and architectures.
  • Tella / Proofmode / C2PA: established protection/provenance mechanisms.
  • Axon / TalkingParents: commercial evidence integrity/report precedent.
  • UCD, XBully, temporal HAN, PI-Bully: academic methods, not Android end-to-end products.
  • DravidianCodeMix / HASOC: offensive-content data, not private escalation ground truth.
  • Laya multilingual / runtime: calibration weaknesses and quantization parity gates.
  • Selective Conformal Risk Control: general evaluated preprint method, assumptions apply.
  • Notification API / Keystore: official platform/security boundaries.
  • ML Kit / Tesseract / whisper.cpp: extraction components, not target-language quality proof.
  • ONNX Mobile / LiteRT-LM: runtime feasibility, not checkpoint parity or mid-range guarantees.
  • Qwen small baseline / MiniLM embedding candidate: real model cards; not validated Sakshi recommendations.

Search absence does not establish novelty. Secondary-index-only CARE/SendWise/CIDER-CB performance claims were excluded pending primary verification. No source repository was executed or implementation-audited. Sources are mutable; pin revisions before building.

Research implication: build reliable supported intake, then show what happens when evidence is missing, duplicated, corrected or selectively disclosed. That is more defensible than “AI + vault + timeline”.
